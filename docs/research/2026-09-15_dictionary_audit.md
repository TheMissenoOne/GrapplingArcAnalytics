## What the first run says (2026-09-15)

Three findings, in the order they matter.

**1. The dictionary is not the bottleneck the class distribution suggested — reachability is.**
29 of 209 curated entries have no node in `data/frame_pdf/node_library.json`, the file whose
labels are printed on every sheet and the only vocabulary `vision_dataset.build_labels`
accepts. A reader is never offered those labels, so they cannot receive a frame no matter how
much footage is audited. That bucket has to be closed by reconciling the two vocabularies, not
by labelling.

**2. That drift is already destroying audited labels.** `analysis/names.SYNONYMS` gained
`north south choke → northsouth choke` on 2026-09-14 (806e338, N1 batch 2). `node_library.json`
was generated 2026-09-01 and has `north south choke`, not `northsouth choke`, so four
human-audited `North South Choke` frames now canonicalise onto a key the library lacks and are
dropped as `off_library_label` — the build's drop counter went 1 → 5 between the 09-02 build
and this one. Prod's `technique_nodes` DOES carry `northsouth choke`, so the fix is one
command: `uv run python scripts/frame_pdf.py --dump-library`, which regenerates the library
from prod. **Rule this establishes: the node library is downstream of `names.SYNONYMS` and
must be regenerated in the same push as any synonym change.**

**3. The zero bucket cannot be queued from what exists.** 95 curated entries have no verified
frame, and 87 of them have no candidate frame proposed by ANY read — the reads we have
concentrate on the same common positions the model already gets right. Those techniques are
frequent in the corpus (`Leg Drag Pass` 58 events, `Bridge (Upa Escape)` 49, `Smash Pass` 43)
and the corpus rows carry video, which is exactly what `scripts/dictionary_seed.py` turns into
frames. The audit queue is therefore only as deep as the seed is wide.

Two smaller ones: no entry carries a written visual definition yet (item (c) of the owner's
goal is entirely unstarted), and the top candidate labels are dominated by GENERIC outcome
words — `Escape` 189, `Tap` 139, `Finish` 113, `Submission` 69 — which are reading artefacts,
not missing techniques. They want a "reject, this is not a technique" verdict recorded once,
not 500 frames.
