## Goal
Public-site **Decision Flow** experience: procedural instructional flowcharts from
perspective sequences (athlete action → opponent condition → athlete response),
deterministic precomputed layouts, generated by Analytics, dependency-free site renderer.

## Context
Opponent events are dropped by `build_athlete_graph()` (actor == "you" only) and
`athlete_elo._your_entries()`. `_perspective_view()` (db/repository.py:540) already keeps both
actors. This card adds a parallel projection: decision patterns, without touching the execution
graph/ELO. Site plan: docs/superpowers/plans — user spec (decision-flowcharts plan).
Mirror contract: `cond:`-prefixed opponent-condition keys, GA_FLOWCHART payload, FlowchartPayload
schema. Future: app viewer consumes precomputed payloads.

## Execution Plan
1. `analysis/perspective_sequence.py` — shared perspective converter (both actors, ts, tri-state
   success, neutral actor); refactor `db/repository._perspective_view` onto it (regression tests).
2. `analysis/opponent_conditions.py` — ConditionKind, curated CONDITION_ALIASES + pattern rules +
   event-type mapping + deterministic fallback; bundle classifier (≤2 distinct, dedupe, composite).
3. `analysis/decision_flow.py` — window extractor + aggregation + CLI; failure-terminal semantics;
   success only from explicit flags / terminal submission; confidence via Beta posterior.
4. `analysis/flowchart_compiler.py` + `data/flowchart_definitions.json` — observed+expert merge,
   branch scoring, limits, portals, stable IDs.
5. `analysis/flowchart_layout.py` — deterministic desktop (root-centered 4-sector) + compact
   (vertical) layouts, fixed node dims, validation.
6. `export/flowchart_site.py` + integration in `export/site_data.py` (prune globs, ItemCache,
   sitemap/robots, nav/footer).
7. Site repo: `site/flowchart.js`, `site/flowchart.css`, `site/flowcharts.html` + regenerated
   output (hand-written files preserved).
8. Tests: perspective/conditions/extraction/compiler/layout/export; graph+ELO regression guard.
9. Quality gates: `uv run pytest tests/ && uv run ruff check . && uv run mypy .`

## Acceptance Criteria
- [ ] Alternating exchange renders as 3 distinct stages (action → condition → response)
- [ ] Athlete graphs, ELO, breakdown payloads byte-identical (regression tests)
- [ ] `uv run python -m export.site_data` emits flowcharts-data.js + flowchart-<slug>.html/-data.js, prunes stale, preserves hand-written files
- [ ] Layout deterministic across runs; no overlap; no browser layout
- [ ] GA_FLOWCHART payload app-ready (no browser-only fields)

## Test Plan
Synthetic fixtures (no network): windowing matrix, boundary cases, aggregation dedupe,
compiler limits/portals, layout determinism/overlap, export prune-preserve.
